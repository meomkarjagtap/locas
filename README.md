# Locasdot

[![Deployment](https://img.shields.io/badge/deployed-Vercel-blue)](https://locasdot.vercel.app)
[![License](https://img.shields.io/badge/license-Apache%202.0-green)](./LICENSE)

Locasdot is a modern cloud-based software solution designed to simplify license management, compliance, and user onboarding.  
It provides a seamless workflow for businesses and individuals to manage software renewals, payments, and access — all unified under the Locasdot brand and deployed globally via Vercel.

---

## 🌐 Website
Visit the live application: **[locasdot.vercel.app](https://locasdot.vercel.app)**

---

## ✨ Overview
- **License Renewal Workflow**: Automated license updates tied to Firebase Auth UID.  
- **Payment Integration**: Secure transactions powered by Razorpay.  
- **Unified Branding**: Locasdot as the product, Locastitch as the business entity.  
- **User-Centric Design**: Streamlined onboarding and renewal experience.  
- **Cloud Deployment**: Fast, reliable hosting on Vercel with global edge network optimization.
